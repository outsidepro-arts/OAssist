# Участие в разработке OAssist

Обсуждения и документация — на **русском** языке. Сообщения коммитов и ветки — на английском ([Conventional Commits](https://www.conventionalcommits.org/)).

Инварианты проекта зафиксированы в [`AGENTS.md`](AGENTS.md), история инженерных решений — в [`MEMORY.md`](MEMORY.md). Перед началом работы сверьтесь с ними.

## Требования

* **Совместимый JDK (минимум 17)**, Android SDK (API 36), Gradle Wrapper проекта (`gradlew.bat` — не глобальный `gradle`). JDK выбирается через `JAVA_HOME` или `java` из `PATH`, без общего абсолютного пути и фиксации конкретной установки.
* Только **Kotlin**. Без Java, reflection-based DI и аннотационных процессоров, кроме Room (KSP).

## Сборка и проверки

```bat
.\gradlew.bat :app:compileDebugKotlin          :: компиляция графа модулей
.\gradlew.bat testDebugUnitTest                 :: юнит-тесты
.\gradlew.bat :<module>:lintDebug               :: Android Lint
.\gradlew.bat :app:assembleDebug                :: отладочный APK
```

Сборка использует штатные Gradle/Kotlin daemon и параллельное выполнение проектов. Необязательные синхронные обёртки и локальная диагностика OpenCode описаны в [`tools/README.md`](tools/README.md).

`clean`, `--offline` и `--no-build-cache` применяйте для конкретной задачи; они не требуются перед обычной сборкой и не диагностируют зависание агентского клиента.

## Правила изменений

1. **Язык.** Новые строки — сразу в `values/strings.xml` (русский) и `values-en/strings.xml` (английский). Хардкод текстов в коде запрещён; `contentDescription`/`stateDescription` — через ресурсы в обеих локалях.
2. **Доступность (TalkBack) — обязательна.** Каждый новый/изменённый UI-элемент: имя и роль, `stateDescription` для состоящих, `heading()`/`paneTitle` для секций, touch target ≥ 48dp, у жестов — кнопочная альтернатива и `CustomAccessibilityAction`. Используйте канонические компоненты из `core/ui/components` и хелперы из `core/a11y`. **Definition of Done каждого PR включает TalkBack-проход.**
3. **Секреты** (API-ключи, токены, пароли, заголовки) — только через `SecretStore` (Android Keystore). Не логировать, не отображать повторно, не писать в БД/экспорт/бэкап.
4. **Никаких захардкоженных списков моделей** — список моделей только запросом к провайдеру, фолбэк — ручной ввод `modelId`.
5. **Ошибки** — через `Result`/сейф-типы из `core/model`, не голые `throw` сквозь слои. Зависимости направлены: `feature/*` → `core/*` → `core/model`; никогда не тяните `feature` в `core`.
6. **Комментарии** — только для неочевидных инвариантов и хаков под OEM. Без `TODO`/заглушек без задачи в `MEMORY.md`.
7. **Тесты** — для парсеров, чистой логики и протокольных маппингов (юнит, JVM). Факт прохождения тестов и линта указывайте в PR.

## Definition of Done

1. Юнит-тесты зелёные (`testDebugUnitTest`), линт зелёный (`lintDebug`).
2. Строки ru + en, без хардкода в UI.
3. TalkBack-проход по затронутым экранам.
4. Секреты не попадают в логи, историю, экспорт и бэкапы.
5. Новая модель/провайдер — только через запрос списка у провайдера или ручной ввод id.

## Чего не делать

* Не коммитить секреты (`.env`, `local.properties`, ключи, `keystore/`) — проверяйте `git status`.
* Не менять `applicationId`/`namespace` (`ru.outsideproarts.oassist` зафиксирован).
* Не добавлять тяжёлые зависимости «на будущее» — репозиторий частично работает на вендоренных артефактах (`vendor/maven`).
* Не коммитить без явной просьбы; коммиты — на английском.
