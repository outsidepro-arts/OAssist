# OAssist

![License: MIT](https://img.shields.io/badge/License-MIT-green.svg) ![Platform: Android 12+](https://img.shields.io/badge/Platform-Android_12%2B-3DDC84?logo=android&logoColor=white) ![Language: Kotlin](https://img.shields.io/badge/Kotlin-100%25-7F52FF?logo=kotlin&logoColor=white) ![Vibe Coded with AI](https://img.shields.io/badge/Vibe_Coded-with_AI-8A2BE2)

**OAssist** — клиент LLM-агента для Android с открытым исходным кодом, способный заменять стандартного системного голосового помощника. Приложение может вызываться поверх любого экрана стандартным жестом ассистента, выполнять действия на устройстве через системные интенты, сервис специальных возможностей (Accessibility) и привилегированные интерфейсы (Shizuku / Root), а также работать в режиме классического чата и обрабатывать контент из системного меню «Поделиться».

Проект ориентирован на личное использование, распространяется вне Google Play и разработан с жестким соблюдением стандартов доступности для программ экранного доступа (TalkBack).

> **О разработке:** Проект создан методом вайбкодинга (AI-assisted development) в связке с ИИ-агентами. Архитектурные инварианты, правила доступности и история инженерных решений фиксируются прямо в репозитории (`AGENTS.md`, `MEMORY.md`), что позволяет агентам вести разработку последовательно, с соблюдением строгих требований к коду и тестам.

## Примеры запросов

| Вы говорите | Что происходит |
|---|---|
| «Поставь будильник на семь» | Модель понимает просьбу, будильник установлен |
| «Найди Сашу и напиши ему „я опаздываю“» | Контакт найден, SMS отправлена (с подтверждением) |
| «Включи фонарик» | Фонарик включён |
| «Открой ВК и напиши Антону привет» | Приложение открыто, сообщение написано |
| «Прочитай эту статью и скажи суть» | Страница прочитана, суть пересказана |
| «Запомни: я не ем сладкое» | Записано в память ассистента |

## Основные возможности

### Три режима работы

Для каждого режима настраиваются собственные провайдер, модель, системный промпт и параметры озвучки:

* **Ассистент (`ASSISTANT`)** — вызывается системным жестом помощника. Работает как компактная панель поверх текущего приложения или в режиме уведомления (без перекрытия экрана). При вызове может получать контекст текущего экрана и скриншот. Поддерживает непрерывный голосовой диалог и управление кнопкой гарнитуры (Play/Pause).


* **Чат (`CHAT`)** — полноценный интерфейс диалога внутри приложения. Поддерживает хранение истории в локальной базе данных (включая вложения и вызовы инструментов), нечеткий поиск по диалогам, автоматическое именование чатов моделью, отображение цепочки рассуждений (reasoning) и статистику расхода токенов/стоимости.


* **Отправка (`SHARE`)** — точка входа из системного меню «Поделиться». Позволяет переслать текст, изображение или файл напрямую в новый или существующий диалог с моделью.



### Провайдеры и протоколы

Приложение не содержит жестко заданных списков моделей — перечень всегда запрашивается у сервера провайдера либо вводится вручную. Поддерживаются:

* **OpenAI-совместимые API** (`/v1/chat/completions` и `/v1/responses`).


* **Anthropic** (`/v1/messages`, включая поддержку extended thinking).


* **Google Gemini** (`/v1beta/models/{id}:streamGenerateContent`).


* **OpenCode (Zen / Go)** — автоматическая маршрутизация протокола конкретной модели (через каталог models.dev, эвристику или ручной выбор).



Поддерживается передача изображений (Vision) и прямой аудиоввод (для моделей с поддержкой `audio_in`).

### Встроенные инструменты (50+ инструментов)

Агент может взаимодействовать с системой на трех уровнях доступа:

1. **Системные интенты и API (`intent.*`, `notify.*`, `web_*`):**
* Звонки, чтение журнала вызовов, поиск контактов, отправка SMS.


* Управление будильниками, таймерами и событиями календаря.


* Просмотр списка установленных приложений, их Activity и прямой запуск с параметрами.


* Чтение активных уведомлений, переход по ним, очистка и быстрый ответ (`RemoteInput`).


* Управление медиа-плеерами и получение метаданных текущего трека (`MediaSession`), управление фонариком, громкостью, яркостью и режимом «Не беспокоить».


* Получение свежих координат геолокации и сводки состояния устройства (батарея, сеть, экран, звук).


* Поиск в интернете (парсинг выдачи DuckDuckGo, Google, Яндекс, Bing, Brave, Ecosia, Mojeek, Mail.ru) и чтение веб-страниц с конвертацией в Markdown (статический запрос или рендер через фоновый WebView).




2. **Сервис специальных возможностей (`ui.*`):**
* Снятие текстового слепка дерева элементов экрана (`ui_get_screen`), клики, долгие нажатия, ввод текста, скролл, свайпы, глобальные действия (Назад, Домой, Недавние).


* Просмотр и выполнение скрытых Accessibility-действий на узлах интерфейса (`ui_get_actions`, `ui_perform_action`).


* Создание скриншотов всего окна, заданной области или конкретного элемента интерфейса (с автоматическим скрытием панели ассистента на время снимка).


* Сервис работает строго пассивно: запрашивает дерево экрана только по команде инструмента и не мешает работе TalkBack.




3. **Привилегированный доступ (`shell_*` через Shizuku или Root):**
* Выполнение read-only shell-команд из белого списка, чтение и запись системных настроек (`system` / `secure` / `global`).


* Использование `input tap/swipe/keyevent` в качестве резервного механизма жестов.


* Автоматический обход ограничений фонового запуска Activity на прошивках MIUI / HyperOS.




### MCP, память и навыки

* **MCP-клиент:** подключение внешних серверов по протоколу Model Context Protocol (Streamable HTTP, поддержка Bearer-авторизации и пользовательских заголовков).


* **Долговременная память (`MEMORY.md`):** агент может сохранять, читать и удалять факты о пользователе между сессиями.


* **Навыки (`Skills`):** подключаемые инструкции в формате Markdown, которые пользователь может создавать и переключать в настройках, а агент — подгружать по необходимости.



### Доступность (TalkBack) и работа с речью

Доступность для незрячих пользователей — базовое архитектурное требование проекта (соответствие WCAG 2.2 и практикам CVS Health Compose Accessibility):

* Все интерактивные элементы имеют корректные роли, описания состояний, заголовки секций и сгруппированные узлы фокуса; дублирование жестов кнопками и `CustomAccessibilityAction` обязательно.


* Два независимых речевых потока:


* **Озвучка ответа:** выключена, через системный TTS (с выбором движка, языка, голоса, скорости, тона и громкости) или напрямую в **экранный чтец (Screen Reader)**. В режиме экранного чтеца текст передается по предложениям через очередь анонсов (`TYPE_ANNOUNCEMENT`), не перебивая навигацию и не вызывая повторного чтения всего текста при обновлении стрима.


* **Нарратив работы:** проговаривание шагов агента (вызовы инструментов и их статус) отдельно от основного ответа, исключительно через экранный чтец.




* Приложение очищает Markdown-разметку перед отправкой текста в синтезатор речи.


* Настроен корректный перехват аудиофокуса (приглушение музыки при ответе, пауза медиа и приостановка речи TalkBack на время работы микрофона).


* Опциональное звуковое сопровождение событий агента (отправка, размышление, чтение/запись инструментами, запрос разрешения, готовность ответа).



### Безопасность и приватность

* **Хранение секретов:** все API-ключи, токены и заголовки шифруются через Android Keystore (`AES-256-GCM`) и хранятся в защищенном хранилище устройства (с поддержкой Direct Boot для работы ассистента на заблокированном экране). Секреты никогда не отображаются повторно в интерфейсе, не попадают в логи (используется redacting-логгер) и исключены из резервных копий (`allowBackup="false"`).


* **Контроль действий (Approval Gate):** все инструменты разделены по категориям и типу доступа (Чтение / Запись). Поддерживаются готовые пресеты безопасности и гибкие разрешения при вызове: разрешить однократно, на текущую сессию, запомнить выбор навсегда или отклонить.

## Технический стек и архитектура

* **Язык:** 100% Kotlin (Coroutines, Flow, `kotlinx.serialization`).


* **Платформа:** Android 12+ (`minSdk 31`, `compileSdk 36`).


* **UI:** Jetpack Compose + Material 3 (светлая и темная темы, контрастность AA).


* **Хранение данных:** Room (KSP) для истории чатов, Preferences DataStore для настроек и зашифрованных секретов.


* **Сеть:** Ktor Client 3 (SSE, политика автоматических повторов при сбоях сети и кодах 5xx/429, мониторинг подключения).


* **DI:** ручное внедрение зависимостей (`AppGraph`) без использования рефлексии и кодогенераторов вроде Hilt/Koin.

```text

core/

  a11y/                 Семантика, модификаторы и инварианты доступности для TalkBack
  ui/                   Канонические доступные Compose-компоненты, парсер и рендерер Markdown

  device/               Интеграция с Shizuku и Root (PrivExecutor, UserService, политики shell)
```

## Сборка проекта

### Требования

* **JDK:** совместимый с Gradle Wrapper и Android Gradle Plugin проекта (минимум 17). Wrapper использует `JAVA_HOME` или `java` из `PATH`; конкретная установка JDK в проекте не закреплена.


* **Android SDK:** API 36


* **Система сборки:** Gradle (через встроенный Gradle Wrapper `gradlew` / `gradlew.bat`)


### Основные команды

Компиляция и проверка кода (Windows):

```bat
.\gradlew.bat :app:compileDebugKotlin
.\gradlew.bat testDebugUnitTest
.\gradlew.bat lintDebug
```

Сборка отладочного APK:

```bat
.\gradlew.bat :app:assembleDebug
```

Готовый файл будет находиться в `app/build/outputs/apk/debug/app-debug.apk`.

Для сборки подписанного релизного APK (`:app:assembleRelease`) требуется файл `keystore.properties` в корне проекта (для генерации ключа предусмотрен скрипт `tools/gen-keystore.ps1`). Без него релизная сборка сформирует неподписанный пакет.

Подробности (обёртки запуска, релиз, тесты и локальная диагностика OpenCode) — в [`tools/README.md`](tools/README.md).

## Настройка после установки

1. **Провайдер и модель:** перейдите в `Настройки → Провайдеры`, добавьте профиль (укажите Base URL и API-ключ). Затем в настройках нужных режимов (`Чат`, `Ассистент`, `Отправка`) выберите провайдера и загрузите список моделей.


2. **Назначение помощником по умолчанию:** в системных настройках Android выберите OAssist в качестве цифрового помощника по умолчанию (`Приложения → Приложения по умолчанию → Цифровой помощник`), чтобы вызывать его стандартным жестом.


3. **Специальные доступы (опционально, в разделе `Настройки → Ассистент`):**
* *Поверх других окон* — для отображения компактной панели ассистента поверх приложений.


* *Сервис специальных возможностей (Доступ к экрану)* — для чтения экрана и выполнения нажатий/жестов агентом. (На Android 13+ при установке из APK может потребоваться предварительно включить «Разрешить ограниченные настройки» в системном экране «О приложении»).


* *Доступ к уведомлениям* — для чтения уведомлений, ответа на них и получения метаданных играющей музыки.


* *Shizuku / Изменение системных настроек* — для привилегированных команд и управления яркостью экрана.



4. **Для пользователей Xiaomi (MIUI / HyperOS):** чтобы система не блокировала открытие приложений и установку будильников из фонового режима оверлея, включите для OAssist «Автозапуск», установите контроль активности в «Без ограничений» и разрешите фоновый запуск через кнопку «Выполнить через Shizuku» в разделе `Настройки → Ассистент → Запуск в фоне` (либо через ADB: `adb shell appops set ru.outsideproarts.oassist 10021 allow`).

## English

**OAssist** is an open-source LLM agent client for Android that can replace the system voice assistant. It is invoked with the standard assistant gesture over any screen, performs on-device actions through intents, the AccessibilityService and privileged interfaces (Shizuku / Root), and also works as a classic chat and as a share-sheet target.

* **Three modes** — Assistant (overlay panel or notification mode, continuous voice dialog), Chat (local history with fuzzy search, auto-titling, reasoning stream, token/cost stats) and Share (text, images, files from other apps). Each mode has its own provider, model, system prompt and speech settings.
* **Providers** — any OpenAI-compatible API (Completions / Responses), Anthropic (`/v1/messages`, extended thinking), Google Gemini, and the OpenCode aggregator with automatic per-model protocol routing. No hardcoded model lists: models are fetched from the provider or entered manually. Vision and audio input supported.
* **55 built-in tools** across three privilege tiers: system intents (calls, SMS, alarms, calendar, apps, notifications, media, web search/fetch), Accessibility UI automation (screen snapshot, taps, text input, scrolling, screenshots, hidden node actions) and privileged shell commands via Shizuku / Root. Plus an MCP client, long-term memory and Markdown skills.
* **Accessibility-first** — full TalkBack support (WCAG 2.2), two independent speech streams (answer TTS or screen reader, work narration), audio focus handling, optional sound effects.
* **Security** — secrets encrypted with Android Keystore (AES-256-GCM), excluded from backups and logs; category-based approval gate with per-action, per-session and persistent grants.

Requires Android 12+, JDK 21 to build: `gradlew assembleDebug`. Interface languages: Russian (default) and English.
