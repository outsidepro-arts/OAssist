# Указатель истории разработки

Текущие требования — в [AGENTS.md](../../AGENTS.md), состояние, решения пользователя
и единый список открытых вопросов — в [MEMORY.md](../../MEMORY.md). История нужна
для причин решений, диагностики регрессий и прежних ручных сценариев. Она содержит
отменённые инструкции; найденную старую команду нельзя автоматически считать актуальной.

## Как найти нужное

1. Выберите тему в таблице. Ищите указанное слово в нужном файле, затем читайте
   отдельную запись или небольшой диапазон и соседние записи о смене решения.
2. Не открывайте весь журнал и все темы подряд. Диапазоны ниже — границы поиска,
   а не требование прочесть весь указанный объём. Строки местами очень длинные;
   ограничивайте также объём вывода и уточняйте поиск при усечённом результате.
3. Используйте доступное средство: поиск IDE/редактора, `rg -n -F` либо поиск по
   тексту средствами оболочки. Serena, MCP и специальные инструменты клиента не нужны.
