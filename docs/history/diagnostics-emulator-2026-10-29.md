# Диагностика на эмуляторе — 2026-10-29

После первоначальной проверки подключён emulator-5554, Android 16/API 36.
Установлен ранее собранный `build/artifacts/oassist-diagnostics-debug.apk`.
Приложение до установки отсутствовало; существующие данные приложения не удалялись.

## Автоматическая проверка

Добавлен `app/src/androidTest/kotlin/ru/outsideproarts/oassist/diagnostics/DiagnosticDeviceTest.kt`.
Тестовый APK собран Wrapper в проверенном каталоге исходников. SHA-256 теста
совпадает с рабочей копией. На эмуляторе выполнена команда:

```text
adb -s emulator-5554 shell am instrument -w -e class ru.outsideproarts.oassist.diagnostics.DiagnosticDeviceTest ru.outsideproarts.oassist.test/androidx.test.runner.AndroidJUnitRunner
```

Результат: `OK (3 tests)`, 4,823 секунды.

- Настоящий Android Keystore: содержимое сохранённых файлов не содержит открытого
  текста, экспорт успешно расшифровывается; известный credential удалён из отчёта.
- Медиа исключено из обычного ZIP и корректно включается отдельным выбором.
- Выключение записи, очистка, поздний дочерний ответ и удаление по authoritative
  roots без события привязки не оставляют приватное содержимое в экспортируемых событиях.
- Compose: переключатели имеют Role.Switch и правильное состояние; экспорт требует
  подтверждения, отмена закрывает подтверждение без передачи отчёта.

Тесты используют отдельные каталоги и preferences с UUID. Они удаляют только свои
данные и не подменяют глобальный recorder приложения.

## Ручная проверка

Экран «Настройки → Диагностика» открыт через обычную навигацию приложения.
Ошибки хранилища не показаны, пропусков событий нет.

Подтверждение экспорта открывает системный Sharesheet с ZIP; получатель не выбирался,
отчёт никому не отправлялся. ZIP извлечён из приватного кэша для проверки.
Отдельно проверены CreateDocument/Downloads, кнопка SAVE и сообщение «Отчёт сохранён».
Сохранённый ZIP прочитан с устройства: CRC корректны, присутствуют events.jsonl,
manifest.json и summary.md, droppedEvents/corruptEvents равны нулю.
Как и предусмотрено форматом, manifest не объявляет полноту безусловно подтверждённой.

«Очистить диагностику» показало подтверждение и статус «Диагностика очищена».
Приватный каталог временных ZIP пуст; в хранилище остался только числовой sequence
(1 байт), файлов событий и медиа нет. В AndroidRuntime не обнаружены аварии OAssist.

Локальные копии проверенных ZIP: build/artifacts/emulator-diagnostics-share.zip
и build/artifacts/emulator-diagnostics-saved.zip.

## Границы проверки

TalkBack не установлен и accessibility services выключены. Проверка Compose-семантики
не является проходом с озвучиванием. До первой разблокировки после перезагрузки,
реальные API, активный ответ реальной модели и получение отчёта другим приложением
не проверялись. Отправленный Sharesheet не означает доставку файла получателю.

Android CLI сначала завершился ошибкой доступа к Windows Registry при проверке
обновления. Повтор вне песочницы успешен. Для корректной передачи кириллицы в выводе
CLI локально заданы JVM stdout/stderr/file encoding UTF-8; настройки проекта не менялись.
