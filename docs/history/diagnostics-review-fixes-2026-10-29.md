# Исправления независимого ревью диагностики — 2026-10-29

Свежий reviewer выявил два P1 и два P2 после первоначальной реализации.

## Исправления

- MCP передаёт scoped sanitizer как полный заголовок, так и credential после
  схемы Bearer/Basic. Известный голый токен очищается в ответе, ошибке, событиях
  registry и следующем контексте агента; глобального реестра plaintext нет.
  Дополнительное независимое ревью обнаружило пропуск wire/SSE: исправлена
  передача scoped-секретов через DiagnosticContext, RoutingModelClient и все
  четыре клиента до записи сериализованного запроса и SSE.
- Операция сохраняемого диалога привязывается до отправки запроса через отдельный
  шифрованный mapping вне теряемой очереди событий. Удаление через ChatRepository
  удаляет также failed/in-flight roots, не представленные StoredTurn. При отказе
  сохранения привязки содержимое этого root не записывается, агент продолжает работу.
  Mapping ограничен резервом метаданных и общим дисковым бюджетом.
- При удалении поколение диалога меняется. Поздняя привязка старой операции
  отклоняется, включая удаление и повторное создание assistant_last; новые операции
  сохраняются. Несохранённые CHAT/SHARE привязывают все попытки при сохранении.
  Автосохранение фиксирует владельца и roots до приостановки БД; переключение
  диалога не подменяет эти roots и не присваивает старый chatId новому экрану.
  Устаревшие binding освобождаются только при отсутствии сохранённых событий,
  активного root и ожидающих записи событий. Это предотвращает исчерпание
  резерва метаданных старыми привязками при сохранении активного ownership.
- SAF использует неизменяемый запрос, сохранённый до запуска picker: начало периода,
  выбранные roots, media flag, поколение и идентичность store. Возврат после
  пересоздания экрана не расширяет выборку; неизвестное/устаревшее состояние
  приводит к отказу до открытия выходного потока. После process death требуется
  заново подтвердить экспорт.
- HTTP записывает каждую попытку и terminal event, в том числе последнюю ошибку,
  NoAutoRetry и отмену. Счётчик устанавливается до копирования запроса для retry.
  Добавлены event contracts transport/registry/MCP; обязательный список сборки
  больше не подменяет транспортный контракт одним функциональным retry-тестом.
- Заключительный reviewer нашёл ещё гонку вложенных событий до очереди и остатки
  незавершённой публикации. Удаление теперь учитывает live lineage; запись повторно
  проверяет tombstone корня. При отказе удаляются partial и медиа этой записи;
  после перезапуска удаляются partial и медиа без опубликованного события. Ротация
  не вытесняет первое медиа текущей записи при попытке записать второе.
- Ошибки stream/probe сохраняют очищенное тело до 64 КиБ; при превышении лимита
  тело исключается целиком. Поддержаны ResponseException и сохранённый ответ
  SSEClientException без него в цепочке причин. Исходная ошибка и правила
  fallback/cancellation сохраняются.
